# v3: credit by intervention (11–12 Nov 2026)

Start with **`report.md`**: the write-up and every verdict. The other files, in reading order:

| File | What it is |
|---|---|
| `report.md` | The v3 write-up: what was found, how sure we are, what to claim |
| `theory.md` | Definitions and exact identities: ablation-TD credit, the commitment split (luck vs contribution), per-step Shapley/dividends of the pending game, identifiability |
| `preregistration_v3.md` | Frozen Mode P hypotheses P2–P11 (commit `a08b267`), seeds 5–9 |
| `preregistration_v3_phase3.md` | Frozen headroom-gate hypotheses H3.1–H3.4 (commit `5a73c9c`) + Addendum A (post-hoc, labelled) |
| `preregistration_v3_phase4.md` | Frozen Phase 4 predictions H4.1–H4.4 |
| `confirmatory_results.md` | Generated by `scripts/v3/analyse_prereg.py`: every pre-registered hypothesis, per condition |
| `phase3_results.md` | Generated by `scripts/v3/analyse_phase3.py` |
| `pilot_findings.md` | Exploratory pilots (seeds 0–4) and the decisions they drove |
| `decisions.md` | Every design decision, the alternatives, and why |
| `errata.md` | Corrections to earlier documents (E1–E10) and environment/state changes |
| `related_work.md` | Closest work, how v3 differs, what we claim and do not |
| `PROGRESS.md` | Working log and how to resume |
| `figures/` | Figures used in the report |

## Code

| Path | What it does |
|---|---|
| `src/whoearned/ablation.py` | Persistent stops, exact ablation values, ablation-TD credit, commitment split, pending-game step semivalues, intervention data, active design, table baseline |
| `src/whoearned/critics.py` | MLP, bootstrap ensemble, permutation-invariant set critic (with/without role flags), size transfer |
| `src/whoearned/experiments.py` | All methods in one scoring pipeline (`run_data_cell`), including the V2 controls |
| `src/whoearned/phase4.py` | Exact branching of learned EPyMARL policies; checkpoint evaluation |
| `src/whoearned/envs/` | `env.stop`, `env.clone`, acting/role/amount state fields; lanes, shuffled-role and order-4 layouts |
| `src/whoearned/epymarl_env.py` | Reward modes (team / team_vector / difference via shadow copies) and dropout during training |
| `scripts/v3/` | Grid runners, analysis, statistics, figures |
