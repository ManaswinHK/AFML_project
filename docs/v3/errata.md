## Environment and state changes in v3 (they affect every re-run)

- The global state gains:
  - per-agent **acting** flags (persistent stops);
  - a per-event **pending amount** (E7);
  - per-agent **role flags** ("unit types": is-enabler / is-finisher per event; agents' own observations already carried them).
- Size: `4n + K(5 + n) + 2nK + 1` (was `3n + K(4 + n) + 1`). Agent observations are unchanged.
- **Consequence.** Numbers from v3 runs are not bit-comparable with stored results for methods that read the global state (QMIX, COMA, MAPPO, NA²Q mixers, ATD). The smoke cell shows the size of the shift: QMIX end-to-end L1 0.36 (v3) vs 0.44 (stored) on the same episodes. VDN and ECE do not read the state: ECE reproduces its stored numbers (dividend error 0.50 vs 0.51).
- The test `test_stas_learns_to_decompose_the_return` fails under PyTorch 2.15 on Apple silicon (a training-tolerance test: sums within rtol 0.25). It is not caused by v3 changes (it fails at the unmodified commit in the new environment) and is deselected in v3 test runs. It is noted here so nobody mistakes it for a regression.
