## The project in one minute

In **reinforcement learning (RL)** an agent learns by trial and error from points called *rewards*. In **cooperative multi-agent RL** several agents share one team reward, like a group project with one grade. Usually only some agents did the work, so each agent needs its own *credit*. Deciding who earned what is the **credit-assignment problem**.

Popular methods (VDN, QMIX, COMA, MAPPO, NA²Q, STAS) are judged only by the team's score, because real tasks have no answer key. But **a team can score perfectly while giving credit to the wrong agents.** So we:

1. **Built games with an answer key.** In the *Planted Coalition Gridworld*, agent A pulls a lever that opens a gate (the *enabler*). Later B and C push a crate together (the *finishers*), and the reward arrives after a delay. D and E just wander (*bystanders*). The true credit is computed exactly by **re-playing each game with agents removed**: credit = reward lost without you.
2. **Tested six popular methods against it.** Only **5 of 96** method–setting combinations beat simply splitting the reward equally. The reason is that they ask the wrong question: *"what if A paused for one step?"* (A just pulls the lever a step later, so A gets almost nothing) instead of *"what if A weren't there at all?"* (the gate stays shut and all the reward is lost).
3. **Proposed a fix: credit by intervention.** While collecting training games, a random agent or group *sits out for the rest of the game*. A critic learns how many points the team will still earn, given who is still playing. An agent's credit is *points with you minus points without you*. Credit error drops from **0.5–2** (existing methods) to **0.002–0.07**, and the right team is found in all 12 settings.
4. **Tested generalisation.** It stays near exact with new starting positions every game and at team sizes never trained on (up to 8 agents), and beats the equal split on the public Level-Based Foraging benchmark.

*Credit error* is the L1 distance between a method's credit shares and the true shares: 0 is exactly right, 2 is completely wrong.

## Datasets

**No external dataset is used, and none could be.** This is a reinforcement-learning project: the data comes from agents playing in a simulator. Finding the *true* credit means re-playing every game with agents removed, and a fixed, downloaded dataset cannot be re-played. So all data is generated inside this repository:

| Environment | Source | Notes |
|---|---|---|
| **Planted Coalition Gridworld** | ours: [`src/whoearned/envs/gridworld.py`](src/whoearned/envs/gridworld.py), layouts in [`configs/envs/`](configs/envs) and [`layouts.py`](src/whoearned/envs/layouts.py) | enablers, finishers, bystanders, configurable reward delay; true credit known by construction |
| **Level-Based Foraging (LBF)** | public benchmark (Papoudakis et al., 2021), re-implemented deterministically in [`lbf.py`](src/whoearned/envs/lbf.py) | tested step for step against the official [`lbforaging==2.0.0`](https://github.com/semitable/lb-foraging) (only needed for those reference tests) |
| **Learners** | [EPyMARL](https://github.com/uoe-agents/epymarl) (submodule) | VDN, QMIX, COMA, MAPPO |

Every episode is seeded, so every result can be regenerated. All generated results are committed under [`results/`](results/README.md).

## Reproduce

Five levels, from seconds to days. Each level works on its own.

### Level 0: look at the results (no install)

- Open [`docs/credit_viz.html`](docs/credit_viz.html) in a browser. Pick a setting (reward delay, number of idle agents, enabler slack or critical) and a test game. Press **Play** to watch the agents, then compare any method's credit with the true credit. The lower heatmap always shows the **true** credit step by step; the upper one shows the selected method.
- Read the verdicts in [`docs/results_overview.md`](docs/results_overview.md).

### Level 1: check the code works (≈ 4 minutes on a 6-core desktop; 20+ minutes on a laptop)

```bash
.venv/Scripts/python -m pytest -q -p no:warnings --deselect tests/test_ported.py::test_stas_learns_to_decompose_the_return
```

The deselected test trains STAS for several minutes; run it separately if you like.

### Level 2: one small end-to-end experiment (≈ 5 minutes)

Builds episodes, computes the exact truth by re-playing, trains the critics, and scores every method's credit:

```bash

```

## The method in a few lines of maths

The critic learns *W(s, A)*: the reward still to come from state *s* when only the agents in *A* keep acting. Its training data contains games in which random agents stop for good, and the state carries an acting flag per agent. Write W₋ᵢ for the value when agent *i* has stopped. Agent *i*'s credit at step *t* is

&nbsp;&nbsp;&nbsp;&nbsp;κᵢ(t) = rₜ + W₋ᵢ(sₜ₊₁) − W₋ᵢ(sₜ),&nbsp;&nbsp;&nbsp;&nbsp;and over a game Σₜ κᵢ(t) = R − W₋ᵢ(s₀),

the reward the team got minus what it would expect without *i*. Credit therefore lands when an outcome becomes certain (A at the lever pull), not when the reward is paid. Definitions and proofs: [`docs/v3/theory.md`](docs/v3/theory.md). Code: [`src/whoearned/ablation.py`](src/whoearned/ablation.py), critics in [`src/whoearned/critics.py`](src/whoearned/critics.py).

## Research practice

- **Pre-registered.** Hypotheses and decision rules were written and committed before each confirmatory run ([v3](docs/v3/preregistration_v3.md), [v4](docs/v4/preregistration_v4.md), [v5](docs/v5/preregistration_v5.md)). Analyses chosen after seeing the data are labelled *post-hoc*.
- **Corrections are kept.** [`docs/v3/errata.md`](docs/v3/errata.md) lists every correction; [`docs/v5/review_response.md`](docs/v5/review_response.md) answers an external review point by point.
- **Exploration and confirmation use different seeds.** Pilots use seeds 0–4; confirmatory runs use fresh seeds (5–9 in v3, 10–14 in v4).
